# GTC Models

Публичный каталог ZIP-пакетов моделей для GenTC. Репозиторий использует плоскую структуру: лицензия, каталог и ZIP-архивы лежат в корне. Вложенные папки и GitHub Releases не используются.

## Структура

```text
GTC-Models/
├── LICENSE
├── README.md
├── models_catalog.json
├── GTC-Base-1.0.0.zip
└── GTC-Advanced-1.0.0.zip
```

`LICENSE` уже находится в репозитории — сохрани существующий файл. Лицензия репозитория не обязательно распространяется на сторонние веса, датасеты или компоненты внутри каждого ZIP.

## Добавление модели

1. Подготовь ZIP-пакет модели и положи его прямо в корень репозитория.
2. Внутри ZIP должна быть одна верхняя папка, указанная как `archive_root`. В ней обязателен `model.json`.
3. Поля `id` и `version` внутри `model.json` должны совпадать с соответствующей записью каталога.
4. Добавь запись в `models_catalog.json`.
5. Вычисли SHA-256 всего ZIP и укажи его в `sha256`.
6. Опубликуй файлы в ветке `main`.

Пример записи:

```json
{
  "id": "gtc-base",
  "name": "GTC Base",
  "folder": "GTC_Base",
  "version": "1.0.0",
  "description": "Базовый пакет модели GenTC",
  "archive": "GTC-Base-1.0.0.zip",
  "sha256": "ЗАМЕНИ_НА_64_СИМВОЛА_SHA256",
  "archive_root": "GTC-Base-1.0.0"
}
```

PowerShell для получения SHA-256:

```powershell
(Get-FileHash .\GTC-Base-1.0.0.zip -Algorithm SHA256).Hash.ToLower()
```

## Как лаунчер получает файлы

Каталог читается из `models_catalog.json` в корне `main`. ZIP скачиваются по именам из поля `archive` с `raw.githubusercontent.com`. GenTC Launcher закреплён за `AramFermicky/GTC-Models`, принимает только имена файлов из корня этого репозитория и проверяет SHA-256 перед распаковкой. Не добавляй полные URL в каталог.

Текущий `models_catalog.json` намеренно содержит пустой список. Заполняй его только после того, как ZIP-пакет модели подготовлен и его SHA-256 рассчитан.
