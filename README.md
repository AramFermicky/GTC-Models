# GTC Models

Публичный каталог ZIP-пакетов моделей для GenTC. Репозиторий использует плоскую структуру: лицензия, каталог и ZIP-архивы лежат в корне. Вложенные папки и GitHub Releases не используются.

## Структура

```text
GTC-Models/
├── LICENSE
├── README.md
├── models_catalog.json
├── GTC-Model-Name-Version.zip
└── ...
```

`LICENSE` уже находится в репозитории — сохрани существующий файл. Лицензия репозитория не обязательно распространяется на сторонние веса, датасеты или компоненты внутри каждого ZIP. Для сторонних материалов добавляй отдельные сведения о лицензии.

## Добавление модели

1. Подготовь ZIP-пакет модели и положи его прямо в корень репозитория.
2. Внутри ZIP должна быть одна верхняя папка, указанная как `archive_root`. В ней обязателен `model.json`.
3. Поля `id` и `version` внутри `model.json` должны совпадать с соответствующей записью каталога.
4. Добавь запись в `models_catalog.json`.
5. Вычисли SHA-256 всего ZIP и укажи его в `sha256`.
6. Опубликуй файлы в ветке `main`.

Пример записи:

```json
{
  "id": "gtc-base",
  "name": "GTC Base",
  "folder": "GTC_Base",
  "version": "1.0.0",
  "description": "Описание пакета модели GenTC",
  "archive": "GTC-Base-1.0.0.zip",
  "sha256": "ЗАМЕНИ_НА_64_ШЕСТНАДЦАТЕРИЧНЫХ_СИМВОЛА_SHA256",
  "archive_root": "GTC-Base-1.0.0"
}
```

PowerShell для получения SHA-256:

```powershell
(Get-FileHash .\GTC-Base-1.0.0.zip -Algorithm SHA256).Hash.ToLower()
```

## Как лаунчер получает файлы

GenTC Launcher закреплён за `AramFermicky/GTC-Models`. Он читает `models_catalog.json` из корня ветки `main`, а ZIP скачивает по безопасному имени файла из поля `archive` с `raw.githubusercontent.com`. Полные URL в каталоге не используются. Перед распаковкой лаунчер сверяет SHA-256, проверяет пути архива и содержимое `model.json`.

## Текущее состояние репозитория

- `LICENSE` — сохранённая лицензия репозитория.
- `README.md` — эта инструкция.
- `models_catalog.json` — каталог создан, пока содержит пустой список.
- `GTC-0.1.11.0-1g.zip` — исторический архив **полной автономной сборки ядра GTC**, а не пакет модели для вкладки «Модели» лаунчера. Не добавляй его в `models_catalog.json`: внутри нет корневого `model.json` модели.

Добавляй в каталог только подготовленные пакеты моделей, а не архивы всего лаунчера или ядра.
